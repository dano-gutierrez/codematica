# Connected map sources

Four versioned original paintings, one transparent foliage master, and editable mist/mote overlays form the fifty-position campaign landscape. `prompts-v1.json` stores the exact built-in imagegen prompts. Do not author level buttons, text or characters into these paintings.

`npm run game:assets` assembles/blends all four paintings before cutting shared-guard tiles and overlay crops. See [the asset guide](../../README.md) for dimensions, seam rules and renderer behavior, and [the visual review](../../previews/continuous-map/review.md) for the first/final evidence. Generated tiles are outputs, not authoring surfaces.
