# Character direction

`lineup-v2.png` is the common identity reference for Patch, Shambler, Runner and Armored. It refines the existing `../patch-model-sheet.png` concept. `prompts-v2.json` records the full built-in imagegen prompts and source/output paths.

Production animation uses editable SVG parts in the parent folder and `../patch-rig.json`. Portrait masters live in `../portraits/`. Follow the [asset guide](../../README.md) for silhouette, materials and exports.
