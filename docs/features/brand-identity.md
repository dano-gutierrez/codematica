## One-Minute Brief

Patch replaces the generic network/C identity. The user approved option 1's simple large robot head combined with option 5's medium icon, freestanding favicon and slab lettering. The approval covers installation into the project. Original concepts remain in the repository.

## Outcome / Contract

- Web headers and native study headers/sidebar use the simplified Patch head and approved lettering. Home controls keep a spoken Codematica name and a target of at least 44 points.
- Browser favicon PNGs at 16/32/48 pixels and the multi-resolution ICO use the freestanding miniature with real alpha. Apple touch and 192/512 manifest icons use the medium design on teal.
- Native launcher icons use the medium design. iOS receives an opaque 1024px square; Android receives a separate transparent foreground within its safe circle plus teal background. Splash uses the large head on ivory.
- Assets are local and bundled. There are no changes to routes, learning rules, progress or backend storage.
- Original imagery and imagegen prompts are retained. Builds package checked-in raster sources and never regenerate the artwork through a remote service.

## Current State

Source integration and reproducible exports are complete. The [preview sheet](../../assets/brand/preview.png) shows header size, light/dark favicons, native masks and true transparency. Raster masters are provided; vector reconstruction is outside this change. Native launcher/splash changes require a new installed build.

## Scope

### In Scope

Logo/wordmark, favicon, launcher and splash assets; existing brand controls; export freshness and production asset checks.

### Out Of Scope

Game character rigs, theme redesign, store submission, deployment and changes to learning behavior.

### Assumptions

The app retains its light theme. Favicon transparency is also checked against dark browser chrome.

## Detailed Behavior

### UI / UX

Headers use two decorative images within an explicitly named home control. The medium head keeps its cream outline. The operating system supplies launcher corner masking; rounded corners are not baked into the app-icon master.

### Data Model And Persistence

No user data or migrations. `assets/brand/source/` owns raster artwork and generation provenance; exported copies are generated artifacts.

### Business Logic

`brand:assets` uses build-only Sharp for crop/resize/encoding. PNG frames are packaged into the favicon ICO without a new dependency. UI PNGs are sized for high-density headers, while larger masters remain available. Next metadata file conventions serve the ICO and Apple touch icon; explicit metadata links expose the PNG variants, Apple touch icon and static manifest. Keep the explicit `icons.apple` entry: the browser regression caught a missing Apple link when only `icons.icon` was configured.

### Failure And Edge Handling

CI rejects stale exports. Generation checks require transparent corners, visible content, an opaque iOS launcher and safe Android foreground bounds. Production smoke requests each asset and compares its bytes with its expected export.
