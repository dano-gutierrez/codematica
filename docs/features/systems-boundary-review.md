## One-Minute Brief

Lists of API styles, transport generations or database commands can hide incompatible units and guarantees. This path teaches selected distinctions through original paper traces: a fragment versus an HTTP target, an application stream versus transport recovery, routing versus authorization, a log offset versus an external effect, a cursor versus a snapshot, and an ordinary memory address versus device I/O.

## Outcome / Contract

- Six ordered units cover request identity, transport scope, API interaction, derived state, document queries and memory domains. Each has five sections and a five-choice checkpoint.
- Every lesson and checkpoint has selected primary sources with edition and verification date. Fictional examples are original; no private post text, upstream diagram, code or question bank is copied.
- Six skills belong to this path. Each published stage requires its lesson and checkpoint, uses 80% overall/per-skill thresholds and estimates twenty minutes. These are curriculum choices, not external qualifications.
- Existing paths and interview identities remain unchanged, including terminal keypad and programming-contract checkpoints.
- Only questionnaire choices are graded. The paper traces execute no SDK, packet capture, driver, broker, database or external request.
